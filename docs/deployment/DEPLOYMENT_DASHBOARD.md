3. **Deploy Container Apps** (5 min)
   ```powershell
   az deployment group create --template-file infra/main.bicep
   ```

4. **Set Up AI Pipeline** (3 min)
   ```powershell
   .\deploy-ai-training.ps1
   ```

## 🎓 Integration Guides

### Connect Real-Time Overlay to Storage
```javascript
// App.jsx
const fetchLiveData = async () => {
  const response = await fetch('/api/storage/realtime-data');
  const data = await response.json();
  return data;
};
```

### Feed Log Analytics to AI Pipeline
```python
# ai-training-pipeline.py
query = """
ContainerAppConsoleLogs
| where TimeGenerated > ago(30d)
| distinct ClientIP
"""
results = log_client.query_workspace(workspace_id, query)
training_data = export_to_csv(results)
```

### Deploy Models to Container Apps
```bicep
resource containerApp 'Microsoft.App/containerApps@2023-05-01' = {
  name: 'inference-service'
  properties: {
    template: {
      containers: [{
        image: 'your-registry/ml-inference:latest'
        env: [
          { name: 'MODEL_PATH', value: 'blob://ml-models/visitor-behavior-v1' }
        ]
      }]
    }
  }
}
```
